# Hartwell & Rafael Enterprise — hartwellrafael.com

Static site templated from The Co.LLab (same page pattern: header → Omnidirectional
Enterprise™ model ribbon → hero → main points → Continue strip; footer as the index).
Deployed to the Netlify project `hartwellrafael`.

Pages are generated by `node build.mjs` from one layout (nav, ribbon, footer, sitemap);
edit content there, never in the generated .html files. `partials-wheel.svg` is The
Co.LLab's Omnidirectional Enterprise Model™ wheel, unchanged except the enterprise name,
palette and links.
Lives here temporarily, separate from The Co.LLab site (nothing in the parent repo
references it, and it is not part of wearethellab.com). Move it to its own repository
when one exists.

- Pages: Home (hook, services, how to book) · About (mission & vision) ·
  Omnidirectional Enterprise™ (model + blueprint) · The IV Phases™ (company structure) ·
  Services (by phase) · Book a Conversation (scheduler + contact form)
- `styles.css`, `main.js` — design system + menu, reveal, form submit
- Booking: Calendly event type "Hartwell & Rafael Enterprise — Conversation"
  (30 min, Google Meet, live availability, email confirmation)
- Contact form: Netlify Forms (`contact`), submissions in the Netlify dashboard

Deploy: from this folder, `netlify deploy --prod --dir .` (no build step).
